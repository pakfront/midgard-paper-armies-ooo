# Mordor print contrast and consistency refresh

## Validation

All six revisions were visually inspected for complete silhouettes, figure counts, simplified shading and faction colors. Browser tests confirmed all six transparent assets have both clear background pixels and opaque interiors and export together into a valid PDF. Separate Middle-earth Hero/monster and light troop expansion checks also passed (three relevant tests total). The faction export uses the short nameplate `Mordor herald`, matching the existing Hero export test; the full banner-bearer name exceeds the readable label width. Physical print results have not been tested.

Built-in imagegen edits, genuine transparent backgrounds. All six catalog artwork paths were replaced in place at the user's request; IDs remain unchanged. Earlier versions are preserved in Git history.

Palette: charcoal, medium cool iron grey with broad lighter steel highlights, crimson/brick red, warm brown wood/leather, muted ash-grey/grey-olive Orc skin. The Cave Troll keeps distinct slate-grey skin with brighter broad highlights. Clean-print rules remove fine texture and use bold contours with broad shading planes.

Trackers now have six varied figures in a loose formation, following the skirmisher guidelines in AGENTS.md. Existing other figure counts, base dimensions, upright counts and fixed panel heights are preserved.

Reference roles: each asset is its own edit target. Trackers also reference original Mordor spearmen for faction palette. The spearmen received a second cleanup edit to remove mottled steel and edge noise from the first contrast pass.
